# Contributing

Use the [installation/check guide](docs/INSTALL.md), [capability matrix](docs/CAPABILITIES.md)
and [verification profiles](docs/VERIFICATION.md). Keep changes reviewable and run the
public product checks with private phase archives absent. Missing tools/tests fail.
Do not enable privileged automation, expose private records or change customer files.

An agent cannot approve changes to its authority. Protected policy, packaging,
workflow, dependency and execution changes require eligible human review. Retain
author notices and establish rights for contributions/reused/generated material;
the owner's publication/license decisions remain pending. Do not paste secrets.
See [governance](GOVERNANCE.md) and [conduct](CODE_OF_CONDUCT.md).
