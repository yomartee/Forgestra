# Forgestra — Build. Verify. Evolve.

Experimental local repository inspection and planning, with privileged automation disabled.
The current version is 0.2.0.dev0. This is a proposed source-import candidate;
the owner has recorded limited first-party Apache-2.0 intent and reporting choices.
Uncertain rights and other applicable publication gates remain pending; no push is authorized.
See [license scope and provenance](docs/PROVENANCE.md) and [private reporting](SECURITY.md).

Start with the [quickstart](docs/QUICKSTART.md), [capability matrix](docs/CAPABILITIES.md)
and [installation and checks](docs/INSTALL.md). Core Python runtime dependencies are
empty. Optional MCP is a separately installed, client-spawned read-only stdio adapter.
Neither needs a VPS, domain, dashboard or persistent factory service.

Public product checks run from this source tree with private phase archives absent.
They are separate from [private maintainer evidence replay](docs/VERIFICATION.md).
A green product gate does not approve publication or establish production readiness.

General trusted repair approval, OS-isolated customer execution and a remote
publisher are missing. Repair, installation writes, creation, synchronization,
schedules, self-healing, auto-merge, outreach and provider calls remain blocked.
See the [runtime milestones](docs/RUNTIME_BACKLOG.md). Generated web acceptance is
an authored private protocol fixture; real Hasura/OIDC/container acceptance is separate.
